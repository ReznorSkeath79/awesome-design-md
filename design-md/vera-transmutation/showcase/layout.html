01
Thesis

Say it once, plainly

State the plan in one sentence a leader can repeat, then let the rest of the page earn it.

The one sentence

Northwind runs every region on one operations analytics plane, so throughput is measured the same way everywhere. If a leader cannot repeat it after one read, the page is not ready. Keep it concrete: what changes, for whom, and by when.

What follows
  • Twelve evidence items carry the argument.
  • Four decision asks close the page.
  • Every figure below already appears in the text.

Rule of the page
The thesis frames the debate; the evidence settles it. Do not open with history — open with the claim.

Risks

What can stop this

Name each risk and the mitigation beside it; never leave a risk without an owner action.

RiskMitigation
Data governanceRegion-level access rules and a stated retention window before any raw log is read.
Aggregation biasRubric-anchored scoring with verbatim evidence; four-fifths monitoring; human override.
AccuracyRule lists, then a tuned model; a measured error threshold as the gate.
Prompt injectionThe engine owns the flow; region inputs are data, never instructions.
Manual adjustmentEvery override goes to human review, never an automatic pass.
⚠
Show every flag to a human
A flag is a prompt to review, not a verdict. Keep the regional leader, not the model, in control of the outcome.
