# Futura — Concept Design System Analysis

A Swiss-brutalist "future data" poster language derived from NoSpoon Design's
[FUTURE DATA LAYOUTS — Poster Bundle](https://creativemarket.com/nospoon/291576722-FUTURE-DATA-LAYOUTS-%E2%80%94-Poster-Bundle).

Cool light-gray canvas (#e6e8e9), pure black panels, white blocks, and a single
fluorescent volt accent (#dcfc52) — with dictionary-entry typography, mono data
strings, wireframe geometry, barcodes, and sharp 0px corners throughout.

See [DESIGN.md](./DESIGN.md) for the full token system, components, and rules.
