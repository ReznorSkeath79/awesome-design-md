Boards

A board is the unit of work in Northwind. It owns a set of metrics, a set of regions and a schedule. Create one, add regions, publish it — the API is built so the happy path takes four lines.

Python
import northwind as nw

board = nw.Board("cycle-time")
board.metric("cycle_time", window="7d")
board.publish()
Board properties
PropertyTypeDescription
namestringHuman-readable board name.
regionsstring[]Territory keys to include.
schedulecronRefresh cadence. Defaults to daily.
