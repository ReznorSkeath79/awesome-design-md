# Vera Corp — Vera AI and AutoAlchemy Hub Design System

Corporate navy console design shared by the Vera AI apps and the AutoAlchemy Hub (since its
2026-10-01 redesign). **Corp Dark** (`#010D16` canvas, ice-blue `#7FD4FF` accent) and **Corp
Light** (`#E8F0F6` canvas, `#1878AE` accent). Rounded radius ladder (10/12/14/18/28/999), raised
cards on sunken wells, glowing accent, Inter + JetBrains Mono.

See [DESIGN.md](./DESIGN.md) for the full token system, components, and rules.
