01
The idea

Give each machine the job it is built for

One machine doing everything means a render or an AI job can slow a data run, and a power cut stops the pipeline. Splitting the roles removes both problems without changing the pipeline.

The MacBook stays the server

It already runs LocalETL and the Postgres database in production, it is a managed Concentrix device so client data stays on approved hardware, and its battery rides through power cuts.

The Studio does the heavy, interactive work

Development, the in-house AI models, video and animation renders. It has more cores, more memory and twice the memory bandwidth, which is what AI models and renders need.

Nothing has to move again

Production stays where it was proven on 16 October. The Studio is set up fresh as a workstation, so there is no fourth migration of the pipeline in a month.

03
Resilience

The pipeline keeps running when the power goes out

A laptop has its own battery, so the MacBook is the natural home for work that must not stop. The Studio has no battery and stops with the power.

Power cut · pipeline state

The MacBook keeps every job alive on battery; the Studio needs a UPS just to shut down cleanly.

What keeps working

Every job keeps running, the database never takes a hard power-off and scheduled runs fire on time.

What pauses

Internet calls wait if the router loses power too. A small UPS for the router and modem closes that gap.

How long it lasts

About 58 Wh is usable with charging held at 80%, an estimated 5 to 10 hours. We will measure it with a 30-minute unplug test.

⚠
The Studio by contrast
Without a battery it loses in-flight work in a power cut and stops at the encryption login when power returns. That is acceptable for a workstation, not for the pipeline.

Three decisions Needs you

Each one is small; together they make the setup safe and complete.

  1. 1

    Enrol the Studio with IT

    It was bought online, so it is likely not in Concentrix device management yet. User-initiated enrolment avoids wiping it and lets it become the backup server.

  2. 2

    Approve a small UPS budget

    One UPS for the Studio, one for the router and modem, and an external drive for backups. Quotes to follow.

  3. 3

    Decide on in-house AI for the pipeline

    May LocalETL use the in-house AI model instead of Azure for drafting? Prompts would stay on Concentrix hardware. This needs the Gen-AI and privacy review.
