# Futura Dark — Concept Design System Analysis

The dark inversion of the Futura Swiss-brutalist "future data" poster language
(see [../futura](../futura) for the light original, derived from NoSpoon Design's
[FUTURE DATA LAYOUTS — Poster Bundle](https://creativemarket.com/nospoon/291576722-FUTURE-DATA-LAYOUTS-%E2%80%94-Poster-Bundle)).

Cool near-black canvas (#161716), pure black panels, light-gray slabs (#e6e8e9),
and the same single fluorescent volt accent (#dcfc52) — with dictionary-entry
typography, mono data strings, wireframe geometry, barcodes, and sharp 0px
corners throughout. Typography, spacing, and geometry tokens are identical to
the light system; only the surface logic is inverted. The source artwork has no
dark mode, so this variant is an extrapolated derivative, not a sampled analysis.

See [DESIGN.md](./DESIGN.md) for the full token system, components, and rules.
