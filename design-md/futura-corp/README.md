# Futura Corp — AutoAlchemy Hub Design System

The AutoAlchemy Hub's production system: Futura's Swiss-brutalist instrument-panel structure
(0px corners, 1px hairlines, no shadows, Inter Tight + Space Mono) in the Vera dashboards'
corporate navy palette. **Corp Dark** (`#010D16` canvas, ice-blue `#7FD4FF` accent) is the
default; **Corp Light** is the paired day palette.

See [DESIGN.md](./DESIGN.md) for the full token system, components, and rules.
