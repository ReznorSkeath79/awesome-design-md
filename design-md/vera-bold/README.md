# Vera Bold — OVAI / OVCC campaign look

The OVAI (Concentrix AI Interviewer) web app's look, live 2026-10-15: The Drop's bold ad-campaign energy in
Concentrix navy / teal / gold on Vera Hub's numbered-section structure. Two-tone Anton caps headlines (teal line in
dark, navy on a painted teal brush mark in light), whole colour blocks, pill buttons with one gold primary, glass stat
pills on photography wrapped in paint-brush splashes. Worked example: OVAI `/staff/scoring` ("How scoring works").

See [DESIGN.md](./DESIGN.md) for tokens, components, motion and rules. Build stand-alone pages from
[`kit/`](./kit/README.md). `showcase/` holds the layout used by `showcase.html`.
