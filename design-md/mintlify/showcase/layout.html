Boards

A board is a published view of one or more metrics across a set of regions. Boards are rendered from the same markdown source as your documentation, so a change in the source is a change on the board.

defaultIndex number Required

The index of the tab selected when the board first renders.

regions string[]

A list of territory keys to include in every metric view.
