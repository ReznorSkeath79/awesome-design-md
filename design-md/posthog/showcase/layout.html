Workflows

Automate the reports you hate

Set an alert in seconds

Define a threshold once. Northwind watches every region and pages the on-call before the SLA slips.

northwind.alert({
  metric: 'throughput.on_time',
  below:  0.95,
  notify: '#ops-oncall'
})

Tip. Pipe any threshold to Slack, PagerDuty, or a webhook — no glue code.

Success. Alerts resolve themselves when the metric recovers, so the channel stays quiet.

Warning. A region with no data at all counts as a miss — wire your sources first.

Note. Every alert keeps a history you can query with northwind.query().

Getting started

Build your first operations dashboard

A Northwind dashboard is a set of panels on one ledger. Connect a source, pin a metric, and share the board with the whole operations team.

Tip. Start from a template board if you'd rather not build panels by hand.

Connect a data source

import { Northwind } from '@northwind/sdk'
const nw = new Northwind({ key: process.env.NW_KEY })

Pin a metric

Every panel is a query. Pin quarterly throughput and Northwind recomputes the board as the work lands.
