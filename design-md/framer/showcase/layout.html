Questions

The short answers.

What data sources can Northwind connect?

Warehouse management, transport management, order management, and flat-file drops. Streams arrive over webhook or scheduled pull, and every field is mapped to a shared schema.

How fresh is the dashboard?

Continuous. Metrics recompute as events land, with a one-minute roll-up for the slower lanes and a live exception feed for the fast ones.

Do you support region-level access control?

Yes. Roles scope to regions, sites, and boards, so an APAC planner sees APAC without a separate deployment.

Can we export to our own warehouse?

Every board exposes a read API and a scheduled export to object storage, with lineage attached to each metric.

Is there an on-prem option?

On the Enterprise plan, Northwind deploys into your own cluster with data residency pinned to the region you choose.
