Tools

Instrument the whole operation

Query every metric with SQL you already know, then pin the answer to a dashboard.

throughput.sql
select region, avg(throughput) as units_per_min
from northwind.metrics
where ts > now() - interval '24 hours'
group by region
order by units_per_min desc;

Model it once, reuse it everywhere

Northwind Studio is a full workspace for definitions, pipelines, and saved views. Write the query, version the model, ship the dashboard.

Explore the workspace →
model.sql views.yaml
▸ definitions ▸ pipelines ▸ alerts ▸ views 
-- region throughput, trailing 24h
create view region_rollup as
select
  region,
  count(*) as events,
  avg(throughput) as units_per_min
from northwind.metrics
group by region;
nw deploy region_rollup ✓ view deployed · 7 regions · 0.4s nw
